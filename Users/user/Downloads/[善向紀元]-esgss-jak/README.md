## 🌟 專案願景

將ESG（環境、社會、治理）教育轉化為引人入勝的卡牌遊戲體驗，讓玩家在遊戲中學習永續發展概念、認識真實企業案例，並培養實際行動的能力。

### 🎯 核心價值
- **真實內容：** 100%基於真實案例與科學數據
- **趣味學習：** 遊戲化設計，寓教於樂
- **實用價值：** 可執行的永續行動指南
- **社會影響：** 促進企業與個人ESG實踐

---

## 🃏 遊戲機制

### 卡牌類型
- **知識卡 (Knowledge Cards)** - 傳授ESG核心概念
- **案例卡 (Case Cards)** - 展示真實企業實踐案例
- **行動卡 (Action Cards)** - 提供可執行的永續策略
- **事件卡 (Event Cards)** - 模擬真實世界的挑戰與機會

### 對戰系統
- 策略性卡牌對戰
- ESG學習積分系統
- 成就與徽章獎勵
- 即時學習回饋機制

## 🛠️ 技術架構

### 前端技術棧
- **框架**：React 18 + TypeScript
- **建構工具**：Vite
- **樣式**：Tailwind CSS + 自訂設計系統
- **狀態管理**：React Hooks + Context API
- **路由**：React Router
- **圖標**：Lucide React

### 開發環境
- **Node.js**：18+
- **包管理**：npm
- **程式碼品質**：ESLint + Prettier
- **版本控制**：Git + GitHub

### 部署與發佈
- **開發伺服器**：http://localhost:3000
- **生產部署**：Vercel/Netlify (靜態網站)
- **CI/CD**：GitHub Actions (規劃中)

2. **卡牌選擇**：系統隨機發放5張手牌
3. **策略對戰**：點擊卡牌使用攻擊或防禦
4. **學習回饋**：每張卡牌包含ESG教育內容
5. **勝利條件**：率先達到100分或擊敗對手

## 📈 市場機會分析

### 🎯 目標市場區隔

#### 企業市場 (70%營收潛力)
- **企業ESG培訓**：員工永續意識教育

- **供應鏈管理**：價值鏈永續轉型
- **企業社會責任**：CSR報告與溝通

#### 教育市場 (20%營收潛力)
- **學校教材**：108課綱永續教育整合
- **教師培訓**：ESG教學方法與內容
- **大學課程**：永續發展相關學程
- **親子教育**：家庭永續學習工具

#### 個人市場 (10%營收潛力)
- **一般大眾**：ESG意識提升與參與
- **年輕族群**：遊戲化學習偏好者
- **社會創新者**：關注社會議題的行動者
