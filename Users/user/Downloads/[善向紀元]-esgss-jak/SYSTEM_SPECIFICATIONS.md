# ESG善向紀元 - 完整系統規格書

## 系統概述

ESG善向紀元是一個基於React的前端Web應用，專注於將ESG（環境、社會、治理）教育轉化為引人入勝的卡牌遊戲體驗。系統採用現代化架構設計，結合遊戲化學習、數據分析和企業服務功能。

### 核心價值
- **真實內容**：100%基於真實案例與科學數據
- **趣味學習**：遊戲化設計，寓教於樂
- **實用價值**：可執行的永續行動指南
- **社會影響**：促進企業與個人ESG實踐

### 技術棧

#### 前端技術
- **框架**：React 18 + TypeScript
- **建構工具**：Vite
- **樣式**：Tailwind CSS + 自訂設計系統
- **狀態管理**：React Hooks + Context API
- **路由**：React Router
- **圖標**：Lucide React

#### 開發工具
- **Node.js**：18+
- **包管理**：npm
- **程式碼品質**：ESLint + Prettier
- **版本控制**：Git + GitHub
- **測試框架**：Vitest

#### 部署與發行
- **開發伺服器**：http://localhost:3000
- **生產部署**：Vercel/Netlify (靜態網站)
- **CI/CD**：GitHub Actions (規劃中)

## 本期發生的錯誤

### 測試中發現的問題
1. **圖表渲染警告**
   - 問題：HypercubeAiLab組件中圖表寬高為負值或零
   - 影響：圖表無法正確顯示
   - 嚴重程度：中
   - 解決方案：設定最小寬高值或使用aspect比例控制

2. **TypeScript類型警告**
   - 問題：某些介面定義可能不完整
   - 影響：類型安全可能受損
   - 嚴重程度：低
   - 解決方案：完善類型定義

### 系統架構問題
3. **狀態管理複雜度**
   - 問題：全域狀態過於集中
   - 影響：元件耦合度高
   - 解決方案：考慮引入狀態管理庫如Zustand或Redux

4. **效能瓶頸**
   - 問題：大型元件渲染效率低
   - 影響：使用者體驗不佳
   - 解決方案：元件分割和記憶化
